Link contracts to sale orders.

In Odoo it is quite important to have sale orders for anything that is sold to
customers. For instance, if you have a contract to generate recurring invoices
for maintenance services, and a project to record timesheets, it is important
that the timesheet lines are linked to a Sale Order so they are not reported as
non billable.

With this module, each contract line can be linked to a sale order line.
On sale orders, there is a button to view related contracts.

For more advanced contract generation from sale orders, see the
consider the `product_contract` module.
